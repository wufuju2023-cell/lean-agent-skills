## GaLore 的核心，十行

```text
有效权重      W_eff = deq(Ŵ) + P R        # int8 骨架 + 低秩修正
每步          G = dW ;  G̃ = PᵀG ;  在 r×n 上跑 Adam ;  R 累加
每 K 步       折叠：Ŵ ← Q(deq(Ŵ) + P R) ;  R ← 0
每 T 步       刷新：先折叠，再 P ← SVD_r(G) 的前 r 个左奇异向量
```

1. 优化器状态从 `2mn` 降到 `2rn + mr`。
2. 用 SVD 选基的**唯一**严格理由：Eckart–Young——`P = U_{:,1:r}` 使 `‖G − PPᵀG‖_F` 最小，
   最小值是 `sqrt(Σ_{i>r} σ_i²)`。
3. 投影丢掉的正是 `(I − PPᵀ)G`；收敛界里多出一项 ∝ 它的平方，而这一项 GaLore 控制不了。
4. **基不能随便换**：若 `P → P'` 时 `R ≠ 0`，则 `(I − P'P'ᵀ)PR` 在新基里不可表示——
   这不是启发式，是可表示性定理。所以**必须先折叠再刷新**。
5. Adam 的 `M, V` 是**按坐标**存的，换基后旧动量不是新坐标的动量；携带还是重置是可选项，
   但必须明说，且重置时偏差修正的 `t` 要跟着重置。

## 六个会踩的坑

1. **`P` 若用 `randn` 初始化且不刷新，那就不是 GaLore**，是随机子空间适配器：捕获率只有
   `sqrt(r/N) ≈ 0.18`，而且没做 QR 时连投影都不是（实测 `‖PᵀP−I‖_F` 达 2.11）。
   必须来自**梯度 SVD + QR**（本项目 harness 已修好，`--basis svd` 为默认）。
2. **先刷新再折叠会静默丢更新**（见上文第 4 条）。
3. **必须装 error feedback，RTN/SR 是次要轴。** 按"到最优点的距离"测：bf16 18.495%、
   rtn+EF 18.514%、sr+EF 18.536%、裸 rtn 19.280%。所以"用 SR 不用 RTN"是错误的重点。
4. **r 远低于 GaLore 原文的比例**：`16/1024 = 1.6%`、`16/2048 = 0.8%`，原文是 25%。这是折叠误差
   偏大、必须装 EF 的直接原因；而**把 `K` 压小的原因不是折叠，是基会转**（见下条）。
5. **rank 不是调参轴，但判据不是谱阈值。** `dW` 是 token 的求和，主导项是 `n·ȲX̄ᵀ`（秩 1），
   所以单步 `dW` 的 rank 本来就低——**这是代数，解释了为什么 rank 低，不构成"选 16"的证据**。
   验收用的是**端到端 held-out CE 平价**：50 步、只改 `--rank`，r=16 / 32 / 64 得
   4.2568 / 4.2525 / 4.2625，最大差 **0.010 nats** < **0.014** 的重复噪声地板，无 |z| > 1.4。
   谱上的代价是真的、要一起说：r=16 的逐专家能量加权 p10 捕获率 **0.927–0.971**、中位
   0.985–1.000，最差层有 **16–60%** 的单步低于 0.99。
   **旧规则「p10 ≥ 0.99」在装得下的 rank 上无解**：它要 r=128（状态 17.45 GB）。那条规则是在
   死专家 `PR ≈ 1` 的画面上校准出来的，而那个画面本身是 bug。
   `PR(dW)` 的旧读数（1.02–1.04、活专家 1.0037–1.0087）仍是**待重测**（专家 0–7 拿 0 路由 +
   pre-fix norm），`PR(X)` 1.1–2.5 仍是 **UNVERIFIED**；它们已经不再是决策依据。
6. **没有公开的 GaLore-on-MoE 结果**；把 r×n 空间的误差反馈投影回主空间（注入 `Pᵀe`）会丢掉
   `(I − PPᵀ)e`（r=64 时约 94%），那是本项目的设计，不是论文方法。
