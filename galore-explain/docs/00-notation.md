# 00 · 记号与约定（全系列共用）

本系列每一篇都假设读者只读过这一篇。所有记号在这里定义一次，后文不再重复解释。

## 0.1 贯穿全文的对象

| 记号 | 含义 | 形状 |
|---|---|---|
| `L` | 训练损失（标量） | — |
| `W` | 某个线性层的权重矩阵 | `m × n` |
| `x` | 该层的输入（一行是一个 token 的特征） | `n` 维 |
| `y = W x` | 该层的输出 | `m` 维 |
| `G` | 损失对权重的梯度，`G = ∂L/∂W` | `m × n` |
| `m, n` | 输出维、输入维 | — |

约定 `W` 的第 `a` 行第 `b` 列记作 `W_{a,b}`；行索引 `a` 对应"输出通道"，列索引 `b` 对应"输入通道"。
矩阵 `W` 的 Frobenius 范数 `‖W‖_F = sqrt(Σ_{a,b} W_{a,b}²)`。
`σ_1 ≥ σ_2 ≥ … ≥ σ_min(m,n)` 表示 `W`（或 `G`）的奇异值，`U`、`V` 是它的左右奇异向量矩阵。

## 0.2 与本项目代码对应的记号

读代码时按这张表对照（代码在 `/data/train35b/`）：

| 本文记号 | 代码里的名字 | 说明 |
|---|---|---|
| `Ŵ` | `ExpertStore.gq_gu` / `gq_d` | int8 骨架，`torch.int8` |
| `s` | `gq_gu` 同级的 `gs_gu` / `gs_d` | 每输出通道一个浮点尺度，形状 `m` |
| `Q(·)`, `deq(·)` | `ExpertStore._q` / 解量化 | 量化、反量化算子 |
| `P` | `ExpertStore.P_gu` / `P_d` | 低秩基，`m × r`，列正交 |
| `R` | `ExpertStore.R_gu` / `R_d` | 低秩累加因子，`r × n` |
| `P R` | `torch.bmm(P, R)` | 低秩修正项，`m × n` |
| `K` | `--fold K` | 折叠间隔（步） |
| `T` | `--refresh T` | 基刷新间隔（步） |
| `r` | `--rank r` | 低秩秩 |

**有效权重**（本文反复出现的核心公式）：

```text
W_eff = deq(Ŵ) + P R
```

即"一份 int8 骨架 + 一份低秩修正"。所有前向用的是 `W_eff`，而不是 `Ŵ` 本身。

## 0.3 数值格式记号

| 记号 | 含义 |
|---|---|
| `bf16` | 16 位浮点，1 符号 + 8 指数 + 7 尾数 |
| `fp32` | 32 位浮点，1 + 8 + 23 |
| `int8` | 8 位有符号整数，取值 `-128 … 127` |
| `int4` | 4 位有符号整数，取值 `-8 … 7` |
| `q_max` | 该格式的正向上界，int8 为 `127`，int4 为 `7` |
| `⌊·⌉` 或 `round(·)` | 最近取整（half-to-even，与 `torch.round` 一致） |
| `SR(·)` | 随机取整（stochastic rounding） |

## 0.4 优化器记号

| 记号 | 含义 |
|---|---|
| `η` | 学习率 |
| `β₁, β₂` | Adam 的一阶、二阶矩衰减系数（常用 0.9、0.999） |
| `ε` | Adam 的分母平滑项（常用 1e-8） |
| `M, V` | 一阶、二阶矩估计 |
| `M̂, V̂` | 偏差修正后的矩 |
| `t` | 步数（从 1 开始） |
