# 05 · GaLore 的严格推导

## 这一篇讲什么

这一篇从零推导 GaLore（Gradient Low-Rank Projection，梯度低秩投影）。读者只需要会微积分
（链式法则、多元泰勒展开到二阶）和线性代数（矩阵乘法、秩、正交投影、奇异值分解）。
不需要读过 GaLore 论文，也不需要相信任何"梯度是低秩的"这种说法——我们会把它写成一条
可以证伪的**假设**，并且指出它在本文的定理里到底扮演什么角色。

推导分十步，每一步都先说明它在回答什么问题，再给结论。所有定理、引理、命题、推论都编号，
正文互相引用。凡是**经验假设**而不是数学事实的地方，一律用 **假设** 标出。

记号完全遵循 `docs/00-notation.md`：`W` 是 `m×n` 权重，`G = ∂L/∂W`，`P` 是 `m×r` 列正交基，
`R` 是 `r×n` 累加器，`Ŵ` 是 int8 骨架，`s` 是每输出通道尺度，`η` 是学习率，`β₁, β₂` 是 Adam
的衰减系数，`K` 是折叠间隔，`T` 是基刷新间隔，`r` 是秩。**`R` 在本文永远是累加器，不是旋转矩阵；
`P` 永远是投影基，不是置换矩阵。**

## 读完你会知道

- 为什么 GaLore 的第一步必须是"先投影梯度、再做 Adam"，反过来不行（引理 1.1）；
- 为什么用 SVD 取前 `r` 个左奇异向量是**唯一有严格理由**的选择（定理 4.1、推论 4.1）；
- 投影到底丢了什么、丢多少，以及每步的下降保证怎么被这个损失打折（命题 5.1、5.2）；
- 带投影误差的收敛界为什么是 `O(1/√T) + ε_proj²`，以及为什么这个界**不能**直接套到 Adam 上（定理 6.1）；
- 为什么固定不换的 `P` 会把模型的长期更新容量永久锁死在 `r` 维（命题 7.1）；
- 为什么"先折叠、再换基"是一条**可表示性定理**而不是工程习惯（定理 8.1、推论 8.2）；
- Adam 的一阶、二阶矩在换基时什么能带走、什么带不走，以及重置矩为什么必须同时重置 `t`（命题 9.1、9.2）；
- 完整算法、每一步的 flops 与字节数，以及 SVD 摊销到每步到底多贵（命题 10.1）。

## 1. 设定：一阶方法的一般形式

### 1.1 问题

设 `L : R^{m×n} → R` 是训练损失，`W ∈ R^{m×n}` 是某一层的权重。我们只能拿到一阶信息：
第 `t` 步的梯度

```text
G_t = ∇L(W_t) = ∂L/∂W |_{W = W_t}          (1)
```

我们考虑所有形如

```text
W_{t+1} = W_t − η · Φ(G_t)                   (2)
```

的迭代，其中 `Φ : R^{m×n} → R^{m×n}` 是某个**逐元素**（elementwise）映射。所谓逐元素，是指
存在一个标量函数 `φ : R → R`，使得对任意矩阵 `X` 和任意下标 `(a,b)`，

```text
[Φ(X)]_{a,b} = φ(X_{a,b})                    (3)
```

注意 `φ` 可以依赖该坐标自己的历史（这正是 Adam 的情形），但**不依赖其它坐标**。

### 1.2 三个具体例子

**SGD**：`Φ(G) = G`。**Momentum**：`Φ(G_t) = M_t`，`M_t = βM_{t−1} + G_t`。
**Adam / AdamW**：每个坐标独立地做

```text
M_t = β₁M_{t−1} + (1−β₁)G_t ,   V_t = β₂V_{t−1} + (1−β₂)G_t²
M̂_t = M_t/(1−β₁^t) ,   V̂_t = V_t/(1−β₂^t)
D_t = Φ(G_t) = M̂_t/(√V̂_t + ε)                (4)
```

`D_t` 就是"方向"。`M_t, V_t` 与 `G_t` 同形状，都是 `m×n`。式 (4) 里每个坐标只用到自己的
`M, V` 分量，所以 Adam 是逐元素的。（推导见 [`04-adamw.md`](04-adamw.md)。）

### 1.3 下面所有推导真正用到的那条结构性质

式 (2) 的形式本身没什么用。真正被 GaLore 利用的是式 (3)：**`Φ` 逐元素作用**。这条性质有一个
直接后果，而它是整个方法能省内存的根本原因。

**引理 1.1（逐元素映射不与线性投影交换）** 设 `P ∈ R^{m×r}` 列正交（`PᵀP = I_r`），
`G ∈ R^{m×n}`。一般地

```text
Φ(PᵀG) ≠ PᵀΦ(G)                              (5)
```

**证明（反例即可）。** 取 `m = 2, n = 1, r = 1`，`P = (1,1)ᵀ/√2`，`G = (1,2)ᵀ`，`Φ` 为逐元素平方
（一个合法的逐元素映射，用来演示结构）。则 `PᵀG = 3/√2`，`Φ(PᵀG) = 9/2 = 4.5`；而
`Φ(G) = (1,4)ᵀ`，`PᵀΦ(G) = 5/√2 ≈ 3.54`。两者不等。∎

对 Adam 这个具体映射，不等的原因更清楚：`PᵀG` 的第 `i` 个坐标是 `G` 的若干坐标的**线性组合**，
它的量级是这些坐标的量级之和；而 Adam 的分母 `√V̂` 是在**这个组合坐标自己的历史**上估出来的。
把 `G` 先旋转再归一化，与先归一化再旋转，得到的方向不同。

**这条引理的意义。** 如果想省内存，就必须让优化器状态只有 `r×n` 那么大。要做到这一点，只有
两条路：

1. **先投影，再优化**：`G̃ = PᵀG`（`r×n`），在 `r×n` 上跑 Adam，得到 `r×n` 的方向，再用 `P` 映回
   `m×n`。状态是 `r×n`。这就是 GaLore。
2. **先优化，再投影**：在 `m×n` 上跑 Adam，得到 `D`，再算 `PPᵀD`。状态仍是 `m×n`，一点没省。

所以"先投影"不是风格选择，而是唯一可行的顺序。代价是式 (5)：我们优化的不是 `PᵀΦ(G)`，
而是 `Φ(PᵀG)`。§5 会精确说明这个代价有多大。

### 1.4 一条贯穿全文的记号

后面反复出现"在子空间里累加、暂时不写回权重"。定义

```text
R_t ∈ R^{r×n}      第 t 步结束时、当前基 P_t 下尚未折叠的位移
```

它满足

```text
W_t = deq(Ŵ) + P_t·R_{t−1}                    (6)
W_{t+1} = W_t − η·P_t·Φ(P_tᵀG_t)              (7)
```

把式 (7) 减去式 (6)，得到累加器的更新规则：

```text
R_t = R_{t−1} − η·Φ(P_tᵀG_t)                  (8)
```

式 (8) 是本文后面所有算法的核心。注意 `R` 带符号：它是**位移**，不是"下降量"。代码里
`torch.optim.Adam([R])` 做的正是 `R ← R − η·m̂/(√v̂+ε)`，与式 (8) 一致。

> 记号提醒：论文里常把 `PᵀG` 记作 `R`，把累加器记作 `A`。本文按 `00-notation.md` 的约定，
> **`R` 是累加器**；投影后的梯度一律记作 `G̃ = PᵀG`，优化器输出的方向记作 `D`。

## 2. 被利用的观测：梯度的奇异值谱快速衰减

### 2.1 经验事实

在 LLM 训练中，权重梯度矩阵 `G_t` 的奇异值谱通常衰减得很快：少数几个方向的能量占了绝大部分。
把它写成可测的形式：

**假设 2.1（梯度谱衰减）** 存在 `r ≪ min(m,n)` 与常数 `ρ_r ∈ [0,1)`，使得在整个训练过程中

```text
Σ_{i>r} σ_i(G_t)²  ≤  ρ_r² · Σ_i σ_i(G_t)²    对几乎所有 t   (9)
```

等价地，尾能量比

```text
tail_r(G) := ‖G − G_r‖_F / ‖G‖_F,   G_r := Σ_{i≤r} σ_i u_i v_iᵀ     (10)
```

满足 `tail_r(G_t) ≤ ρ_r`。这里 `σ_i` 是 `G` 的奇异值（降序），`u_i, v_i` 是左右奇异向量。

**这是假设，不是定理。** 它说的是关于**我们这个任务、这个模型、这个训练阶段**的一个经验性质。
它没有一般性的证明，而且它对 `r`、对层类型、对训练早/中/晚期都可能不同。

### 2.2 这个假设检验起来很便宜

式 (10) 的分子可以不用 SVD 就估出来：只要 `P` 是任意一个列正交的 `m×r` 矩阵，

```text
χ_P(G) := ‖(I − P Pᵀ)G‖_F / ‖G‖_F           (11)
```

就是"`P` 的张成空间之外还剩多少梯度"。当 `P` 取前 `r` 个左奇异向量时，`χ_P(G) = tail_r(G)`
（由 §4 的定理 4.1）。所以实际做法是：每个刷新点顺手记一次 `χ`，一个额外的矩阵乘法，
成本可以忽略。

### 2.3 文献里唯一可信的实测

我们没有自己测过 Qwen3.6 专家梯度的谱。目前能引用的最接近的测量是 GUM
（`research/galore-survey.md` §3.9，原文 `arXiv:2510.17802`）：在 Gemma-2-9B、`T = 200`、`r = 512` 上，

```text
χ = ‖G − P Pᵀ G‖_F / ‖G‖_F :   刚刷新后 0–20%
                               20 步之内 60–80%
```

（来源：`/data/train35b/research/galore-survey.md` 第 244–247 行。）

这组数字有两个方向相反的含意。坏消息：基腐坏得极快，`T = 200` 时每个区间的绝大部分时间都在
一个"错得离谱"的子空间里工作。好消息：**这个方法能容忍 60–80% 的投影残差还继续训练**。
所以不必为了把 `χ` 压到很小而过度设计。

> **UNVERIFIED**：`χ` 在我们 20,480 个专家矩阵上的实际取值、随 `r` 的变化、以及 gate_up 与
> down 的差异，目前没有任何测量。survey §8 的 E1 实验就是为此设计的。本文后面所有
> "取 `r = 64` 够用"的说法都建立在这个未测的量上。

## 3. 投影拟设

### 3.1 定义

取 `P_t ∈ R^{m×r}`，满足

```text
P_tᵀ P_t = I_r                                (12)
```

定义**投影梯度**

```text
G̃_t = P_tᵀ G_t ∈ R^{r×n}                     (13)
```

和**投影更新**

```text
W_{t+1} = W_t − η · P_t · Φ(G̃_t)              (14)
```

式 (14) 就是 GaLore 的全部内容。剩下的都是它的推论、它的代价、以及它落地时必须补的工程。

### 3.2 更新落在子空间里

**引理 3.1（更新方向在 `P_t` 的列空间内）** 对任意 `X ∈ R^{r×n}`，令 `d = P_t X`。则

```text
P_t P_tᵀ d = d                                (15)
```

即 `d` 是 `P_t P_tᵀ` 这个正交投影算子的不动点。

**证明。** `P_tP_tᵀd = P_tP_tᵀP_tX = P_t(P_tᵀP_t)X = P_t I_r X = P_tX = d`。∎

所以每一步的权重位移都精确地落在一个 `r` 维子空间里。§7 会说明这既是优点（省内存、
天然正则）也是缺点（容量被锁死）。

### 3.3 一阶下降只看见 `G̃`

**引理 3.2（内积恒等式）** 对任意 `X ∈ R^{r×n}`，

```text
⟨G_t, P_t X⟩_F = ⟨P_tᵀ G_t, X⟩_F = ⟨G̃_t, X⟩_F     (16)
```

**证明。** `⟨G, PX⟩ = tr(GᵀPX) = tr((PᵀG)ᵀX) = ⟨PᵀG, X⟩`。∎

这条恒等式是 §5 的全部技术核心：**真实梯度 `G` 在子空间之外的分量，对一阶下降没有任何贡献。**
取 `X = Φ(G̃_t)` 就得到"这一步能降多少"只由 `G̃_t` 决定。

### 3.4 内存记账

优化器状态由三部分组成：基 `P`、一阶矩 `M`、二阶矩 `V`。在 GaLore 里 `M, V` 都是 `r×n`。
如果投影作用在**左边**（式 13）：

```text
state_left  = m·r  +  2·r·n       个元素       (17)
```

如果投影作用在**右边**，即 `G̃ = G Q`，`Q ∈ R^{n×r}` 列正交，更新写成 `W_{t+1} = W_t − η Φ(G̃)Qᵀ`：

```text
state_right = n·r  +  2·m·r       个元素       (18)
```

**命题 3.1（左右两种投影的取舍）** 在相同数据类型下，

```text
state_left − state_right = r·(n − m)          (19)
```

因此左投影更省当且仅当 `n ≤ m`（矩阵"高"）；右投影更省当且仅当 `m ≤ n`（矩阵"宽"）。

**证明。** 直接相减：`mr + 2rn − nr − 2mr = rn − mr = r(n−m)`。∎

这个初等结论在我们的形状上非常有用，因为我们的两个矩阵正好落在条件的两边
（形状取自 `DESIGN.md` §2，与 `00-notation.md` 一致）：

| 矩阵 | `m`（输出） | `n`（输入） | 左投影 | 右投影 | 更省 |
|---|---|---|---|---|---|
| `gate_up_proj` | 1024 | 2048 | `mr + 2rn` = 327,680 元素 | `nr + 2mr` = 262,144 元素 | 右 |
| `down_proj` | 2048 | 512 | `mr + 2rn` = 196,608 元素 | `nr + 2mr` = 294,912 元素 | 左 |

（元素数按 `r = 64` 计：gate_up 的 `P` 是 `1024×64`、`M,V` 是 `64×2048`；down 的 `P` 是 `2048×64`、
`M,V` 是 `64×512`。）

**两个必须说清楚的问题。**

第一，**加进累加器 `R` 之后公式要改。** 式 (17)(18) 只算了论文里的 `P, M, V`。论文的 `W` 是
bf16、每步直接更新，所以 `W` 本身就是累加器；我们的 `W` 是 int8 骨架，`K > 1` 时必须另存一个
`r×n` 的 `R`（式 8）。完整式子是

```text
state = b_P·m·r  +  b_MV·2·r·n  +  b_R·r·n       字节       (20)
```

在推荐配置 `b_P = b_R = 2`（bf16）、`b_MV = 1`（8-bit 矩）下，`2mr + 4rn`。有意思的是，
**把矩从 bf16 减到 8-bit 省下来的那 `2rn`，正好够付累加器 `R` 的 `2rn`**，所以"8-bit 矩 + bf16 累加器"
与"bf16 矩、没有累加器"的总字节数完全相同。这是本项目能同时要 GaLore、int8 骨架和 `K > 1` 的原因。

第二，**不要混用不同来源的绝对数。** 项目里现存三套账（`DESIGN.md` §3.1、survey §4.3、本文）
互相对不上，原因有三个，都能核对：`DESIGN.md` 用 **30,720** 个矩阵（40×256×3），但 `gate_up`
已把 gate 与 up 融合成一个 `[1024,2048]` 张量，真实矩阵数是 **20,480**（survey §1 第 31–32 行）；
它的公式又对每个矩阵都按 `n = 512` 算状态，而 `gate_up` 的 `n = 2048`；survey 的表把 `m ≤ n`
当作规范，于是 `down_proj [2048,512]` 被转置成 `[512,2048]` 再算左投影，等价于对 down 用了右投影。

本文统一用**物理形状 + 左投影**：`gate_up` 是 `1024×2048`，`down` 是 `2048×512`。§06 会给一张
按这个约定算出来的表，并标明每一格的口径。

## 4. Eckart–Young：使用 SVD 的唯一严格理由

### 4.1 我们要解决的问题

式 (13) 里的 `P` 可以取任意列正交矩阵。什么样的 `P` 最好？最自然的判据是：让投影残差
`‖G − PPᵀG‖_F` 最小，也就是让"丢掉的梯度"最少。这个问题有精确答案。

### 4.2 两个引理

**引理 4.1（Frobenius 范数等于奇异值平方和）** 设 `A = UΣVᵀ` 是 `A ∈ R^{m×n}` 的 SVD，
`p = min(m,n)`。则

```text
‖A‖_F² = Σ_{i=1}^{p} σ_i(A)²                  (21)
```

**证明。** `‖A‖_F² = tr(AᵀA) = tr(VΣUᵀUΣVᵀ) = tr(VΣ²Vᵀ) = tr(Σ²VᵀV) = tr(Σ²) = Σσ_i²`。
用到的只是 `U, V` 正交以及迹的循环性。∎

**引理 4.2（von Neumann 迹不等式）** 对任意同形矩阵 `A, B`，

```text
⟨A, B⟩_F = tr(AᵀB) ≤ Σ_i σ_i(A)·σ_i(B)        (22)
```

其中两边都按降序排列，`σ_i = 0` 当 `i > rank`。

这是矩阵版的"重排不等式"（两个向量的内积不超过同序配对的内积）。它的标准证明用 Ky Fan
变分刻画 `Σ_{i≤k}σ_i(A) = max tr(PᵀAQ)`（`P, Q` 取 `k` 列正交），我们不在这里展开；下文只用到
它的结论。**这是本节唯一一个借用的经典结果**，其余全部自足。

### 4.3 主定理

**定理 4.1（Eckart–Young，Frobenius 版）** 设 `A ∈ R^{m×n}`，`p = min(m,n)`，SVD 为
`A = Σ_{i=1}^{p} σ_i u_i v_iᵀ`，`σ_1 ≥ … ≥ σ_p`。对任意满足 `rank(B) ≤ r` 的 `B ∈ R^{m×n}`，

```text
‖A − B‖_F²  ≥  Σ_{i=r+1}^{p} σ_i²             (23)
```

且等号在

$$
B^{*} = \sum_{i=1}^{r}\sigma_i u_i v_i^{\top} = U_{:,1:r}\,\Sigma_{1:r}\,V_{:,1:r}^{\top} \tag{24}
$$

处取得。也就是说，`B*` 是 `A` 的最佳秩 `r` 逼近，最小误差是 `sqrt(Σ_{i>r}σ_i²)`。

**证明。**

*上界（构造）。* 取式 (24) 的 `B*`。则

```text
A − B* = Σ_{i>r} σ_i u_i v_iᵀ                  (25)
```

这是一组正交奇异三元组的线性组合，所以由引理 4.1，

```text
‖A − B*‖_F² = Σ_{i>r} σ_i²                    (26)
```

*下界（任意 `B`）。* 记 `E = A − B`。由引理 4.1 与内积展开，

```text
‖E‖_F² = ‖A‖_F² − 2⟨A,B⟩_F + ‖B‖_F²           (27)
```

对 `⟨A,B⟩` 用引理 4.2：`⟨A,B⟩ ≤ Σ_i σ_i(A)σ_i(B)`。又 `‖B‖_F² = Σ_i σ_i(B)²`，且
`σ_i(B) = 0`（`i > r`）。代入式 (27)：

```text
‖E‖_F² ≥ Σ_i σ_i² − 2Σ_i σ_i σ_i(B) + Σ_i σ_i(B)²
       = Σ_{i>r} σ_i²  +  Σ_{i≤r} (σ_i − σ_i(B))²      (28)
       ≥ Σ_{i>r} σ_i²                                   (29)
```

第一个等号只是把 `i ≤ r` 与 `i > r` 分开：`i > r` 时 `σ_i(B) = 0`，剩下 `σ_i²`；`i ≤ r` 时剩下
一个完全平方。第二个不等号是因为平方和非负。∎

式 (28) 顺便告诉我们等号成立的条件：`σ_i(B) = σ_i(A)`（`i ≤ r`），并且式 (22) 取等
（要求 `A` 与 `B` 的奇异子空间对齐）——这正是 `B = B*`。

### 4.4 推论：最优的 `P`

**推论 4.1（最优投影基）** 在全体满足 `PᵀP = I_r` 的 `P ∈ R^{m×r}` 上，

```text
min_P ‖G − P Pᵀ G‖_F² = Σ_{i>r} σ_i(G)²       (30)
```

最小值在 `P = U_{:,1:r}`（`G` 的前 `r` 个左奇异向量）处取得。

**证明。** `PPᵀ` 是秩 `r` 的正交投影算子，所以 `PPᵀG` 是秩不超过 `r` 的矩阵。由定理 4.1，
任何秩 `≤ r` 的 `B` 都满足 `‖G − B‖ ≥ ‖G − B*‖`。取 `B = PPᵀG` 即得下界
`‖G − PPᵀG‖ ≥ ‖G − B*‖`，而 `B* = U_rU_rᵀG`（把式 24 右乘验证：`U_rU_rᵀG = U_rΣ_rV_rᵀ = B*`）。
取 `P = U_r` 时 `PPᵀG = B*`，等号成立。∎

**这是全文唯一一个"必须用 SVD"的严格结论。** 它说的只是：如果目标是最小化
`‖G − PPᵀG‖_F`，那么前 `r` 个左奇异向量是最优解。它**不**说：

- SVD 是唯一能给出好子空间的方法（随机投影、Flora 的周期重采样也能给出不错的子空间，
  只是不保证最优）；
- 最优的梯度重构等于最优的训练方向（§5 会看到，下降量由 `‖G̃‖` 决定，而不仅是重构误差）；
- 前 `r` 个左奇异向量在每个训练阶段都好（§2 的 `χ` 会随时间变坏）。

## 5. 投影到底丢了什么

### 5.1 残差的精确形式

**命题 5.1（投影残差）** 设 `P` 列正交，`G̃ = PᵀG`。则

```text
G − P Pᵀ G = (I − P Pᵀ) G                     (31)
```

并且当 `P = U_{:,1:r}` 时

```text
‖(I − P Pᵀ)G‖_F² = Σ_{i>r} σ_i(G)²           (32)
```

**证明。** 式 (31) 是恒等式移项。式 (32)：`(I − U_rU_rᵀ)G = Σ_{i>r}σ_iu_iv_iᵀ`，再由引理 4.1。∎

注意 `I − PPᵀ` 是**正交**投影算子（因为 `PᵀP = I`），所以
`‖G‖² = ‖PPᵀG‖² + ‖(I−PPᵀ)G‖²`（勾股定理）。这个分解在 §8 还会再出现一次。

### 5.2 下降引理

**假设 5.1（`L'`-光滑）** `L` 连续可微，且存在 `L' > 0` 使得对任意 `X, Y`，

```text
L(Y) ≤ L(X) + ⟨∇L(X), Y − X⟩ + (L'/2)‖Y − X‖_F²    (33)
```

这是标准的 `L`-smooth 假设（这里用 `L'` 记常数，避免与损失 `L` 混淆）。

**命题 5.2（一步下降的精确分解）** 令 `d_t = P_t Φ(G̃_t)`，`W_{t+1} = W_t − η d_t`。则

```text
L(W_{t+1}) ≤ L(W_t) − η⟨G̃_t, Φ(G̃_t)⟩ + (L'/2)η²‖Φ(G̃_t)‖_F²    (34)
```

**证明。** 把式 (33) 用在 `X = W_t, Y = W_{t+1} = W_t − ηd_t`：
`L(W_{t+1}) ≤ L(W_t) − η⟨G_t, d_t⟩ + (L'/2)η²‖d_t‖²`。由引理 3.2，
`⟨G_t, d_t⟩ = ⟨G_t, P_tΦ(G̃_t)⟩ = ⟨G̃_t, Φ(G̃_t)⟩`；由引理 3.1 与 `P` 列正交，
`‖d_t‖² = ‖P_tΦ(G̃_t)‖² = ‖Φ(G̃_t)‖²`。∎

**这个式子没有任何 `ε_proj` 项。** 这是 GaLore 分析里最容易搞错的地方：**一步之内的下降保证
完全不受投影残差影响**，因为残差方向与更新方向正交（引理 3.2），一阶项根本看不到它。
投影的代价不在"这一步降得少"，而在别处——见 §5.3 与 §7。

### 5.3 取 `Φ = id`：下降被尾能量打折

**推论 5.1（SGD 情形的每步下降）** 取 `Φ = id`，则 `d_t = P_tP_tᵀG_t` 精确是 `G_t` 在子空间上的
正交投影，且

```text
L(W_{t+1}) ≤ L(W_t) − η(‖G_t‖² − ε_t²) + (L'/2)η²(‖G_t‖² − ε_t²)    (35)
```

其中

```text
ε_t² := ‖(I − P_tP_tᵀ)G_t‖_F²                 (36)
```

若再取 `η ≤ 1/L'`，则

```text
L(W_{t+1}) ≤ L(W_t) − (η/2)(‖G_t‖² − ε_t²)    (37)
```

**证明。** `Φ = id` 时 `⟨G̃, Φ(G̃)⟩ = ‖G̃‖² = ‖G‖² − ε²`（勾股），`‖Φ(G̃)‖² = ‖G̃‖² = ‖G‖² − ε²`。
代入式 (34)，再用 `η − L'η²/2 ≥ η/2`（等价于 `η ≤ 1/L'`）。∎

**必须小的是什么。** 式 (37) 说的是：每步至少下降 `(η/2)(1 − ε_t²/‖G_t‖²)‖G_t‖²`。所以要保证
下降速度，需要的是**相对**尾能量

```text
ρ_t := ε_t/‖G_t‖_F = ‖(I − P_tP_tᵀ)G_t‖_F / ‖G_t‖_F       (38)
```

小，而不是 `ε_t` 的绝对值小。梯度整体变小（训练后期）时，绝对残差可以很小，但相对残差不一定小；
反过来，梯度很大时绝对残差可以很大而无害。这直接决定了 §2 的假设 2.1 应该写成比值形式。

### 5.4 一个常被忽略的差别：GaLore 不是"投影 Adam 的方向"

如果先算 `D_t = Φ(G_t)` 再投影，得到的方向是 `P_tP_tᵀD_t`；GaLore 得到的是 `P_tΦ(P_tᵀG_t)`。
由引理 1.1，这两者不同。前者需要 `m×n` 的矩，后者只要 `r×n`——所以后者才是 GaLore。

这不是近似误差，而是**定义上的差别**：GaLore 优化的是一个"把梯度限制在子空间里之后再做自适应
归一化"的目标。它的行为与"全秩 Adam + 事后投影"在数值上会有系统性差异，尤其在 `V` 很小的坐标上
（Adam 的逐坐标归一化会放大这些坐标）。这一点在 §9 讨论基刷新时会再次出现。

## 6. 带投影误差的收敛界

### 6.1 定理

**定理 6.1（非凸、带投影误差）** 假设：

- (A1) 假设 5.1 的 `L'`-光滑成立；
- (A2) `L` 有下界 `L*`，记 `Δ := L(W_0) − L*`；
- (A3) `Φ = id`（本节只证 SGD 情形）；
- (A4) 存在 `ε_proj ≥ 0` 使得对所有 `t`，`E‖(I − P_tP_tᵀ)G_t‖_F² ≤ ε_proj²`。

取 `η ≤ 1/L'`，则对任意 `T ≥ 1`，

```text
(1/T) Σ_{t=0}^{T−1} E‖G_t‖_F²  ≤  2Δ/(ηT)  +  ε_proj²         (39)
```

再取 `η = 1/√T`（当 `T ≥ L'²` 时满足 `η ≤ 1/L'`），

```text
min_{0≤t<T} E‖G_t‖_F²  ≤  (1/T)Σ E‖G_t‖²  ≤  2Δ/√T  +  ε_proj²     (40)
```

**证明。** 对每步用式 (35)。记 `a_t := ‖G_t‖² − ε_t² ≥ 0`。取期望：

```text
E[L_{t+1}] ≤ E[L_t] − η(1 − L'η/2)·E[a_t]
```

因为 `η ≤ 1/L'`，有 `1 − L'η/2 ≥ 1/2`：

```text
E[L_{t+1}] ≤ E[L_t] − (η/2)·E[a_t]            (41)
```

对 `t = 0 … T−1` 求和并望远镜消去：

```text
(η/2) Σ_{t<T} E[a_t]  ≤  E[L_0] − E[L_T]  ≤  Δ    (42)
```

把 `a_t = ‖G_t‖² − ε_t²` 代回，并用假设 (A4)：

```text
(η/2) Σ E‖G_t‖²  ≤  Δ + (η/2)·T·ε_proj²       (43)
```

两边乘 `2/(ηT)`：

```text
(1/T)Σ E‖G_t‖²  ≤  2Δ/(ηT) + ε_proj²          (44)
```

这就是式 (39)。取 `η = 1/√T` 即得式 (40)。常数 `2` 在 `2Δ/(ηT)` 里、`ε_proj²` 的系数是 `1`；
如果不用 `1/2` 这个下界而保留 `1 − L'η/2`，`ε_proj²` 的系数会变成 `1/(1 − L'η/2)`，
在 `η = 1/(2L')` 时是 `4/3`。**这些常数都不重要，重要的是 `ε_proj²` 前面的系数与 `T` 无关。** ∎

### 6.2 这个界怎么读

- 第一项 `O(1/√T)` 是标准 SGD 的速率，与投影无关。
- 第二项 `ε_proj²` 是**平台**（plateau）。只要 `ε_proj > 0` 是常数，平均梯度平方就不可能
  降到零以下。它不随 `T` 衰减。
- 所以"GaLore 收敛"这句话必须说成"收敛到最优值的一个邻域，邻域半径由投影误差决定"。

### 6.3 更贴近实际的比值形式

**推论 6.1（`ε_proj` 正比于 `‖G‖` 时）** 若存在 `ρ ∈ [0, 1/√2)` 使
`ε_t² ≤ ρ²‖G_t‖²` 对所有 `t` 成立，则

```text
(1/T)Σ E‖G_t‖²  ≤  2Δ / (ηT(1 − 2ρ²))         (45)
```

特别地取 `η = 1/√T` 得 `O(1/√T)`，常数被放大 `1/(1−2ρ²)` 倍。

**证明。** 在式 (43) 中用 `ε_t² ≤ ρ²‖G_t‖²`，得
`(η/2)(1 − 2ρ²)ΣE‖G‖² ≤ Δ`，整理即得。∎

**为什么要求 `ρ < 1/√2`。** 当 `ρ² ≥ 1/2` 时，投影丢掉的能量超过一半，上面的论证给出的是
一个空界（右边分母 ≤ 0）。这不是说训练一定失败，而是说"最坏情况下降保证"这条论证路线失效了。
§2.3 引用的 GUM 测量正好落在 `ρ ≈ 0.6–0.8`，即 `ρ² ≈ 0.36–0.64`：**在区间末尾，最坏情况保证
要么很松要么已经失效，但训练仍然能进行**。这提醒我们：定理给的是充分条件，不是必要条件。

### 6.4 三条必须说清楚的警告

1. **定理 6.1 只覆盖 `Φ = id`。** Adam 的更新不是下降方向（它的逐坐标归一化可以让 `L` 上升），
   所以式 (39) 不能直接搬到我们实际跑的算法上。能搬过来的是两条结构性事实：
   引理 3.2（一阶项只看见 `G̃`）和命题 7.1（位移被限制在子空间里）。**不要引用定理 6.1 来证明
   Adam + GaLore 收敛。**
2. **`ε_proj` 不由 GaLore 控制。** 它是任务、模型、训练阶段的性质（假设 2.1）。GaLore 能控制的
   只有 `r` 和刷新间隔 `T`，而这两者只能改变 `ε_proj` 的**经验取值**，不能给它一个上界。
3. **式 (39) 是对 `‖G‖²` 的平均，不是对损失值的保证。** 非凸情形下"梯度小"不等于"到了好解"，
   只说明一阶最优性残差小。

## 7. 为什么必须刷新基，以及刷新能买回多少秩

### 7.1 固定 `P` 的后果

**命题 7.1（固定基把位移永久锁在 `r` 维）** 若对所有 `t` 都有 `P_t = P`，则对任意 `S`，

```text
W_S − W_0 = P·( −η Σ_{t<S} Φ(G̃_t) )  =:  P·R_S       (46)
```

因此

```text
rank(W_S − W_0) ≤ r                           (47)
```

**证明。** 每一步的位移是 `−ηPΦ(G̃_t)`，其列都在 `col(P)` 里；求和仍在 `col(P)` 里；任何
`PX` 的秩不超过 `rank(P) = r`。∎

这不是"近似秩 `r`"，是**精确秩 `r`**。固定基的 GaLore 只能让权重在 `r` 个输出方向上移动，
其余 `m − r` 个方向永远不动。哪怕训练一万步，容量也只有 `r` 维。

**一处必要的精确化。** 式 (46)(47) 在两次折叠之间精确成立。折叠会把 `P R` 量化进 `Ŵ`，
量化误差 `e_fold` 逐元素 ≤ `q/2`，**不在** `col(P)` 里；所以严格说折叠后的位移是
`P R + e_fold`，秩的上界变成 `r + rank(e_fold)`（一般是 `min(m,n)`）。但 `e_fold` 的量级是
`q`，不是容量——它不构成"能往哪些方向走"的限制，只是每步的噪声。这不影响 §7 的结论：
**没有刷新时，模型能表达的新方向仍然只有 `r` 个。**

### 7.2 刷新之后

**命题 7.2（刷新把位移变成 rank-`r` 项之和）** 设每 `T` 步换一次基，第 `j` 个区间的基为
`P^{(j)}`，区间内的累加器为 `R^{(j)}`（折叠后归零）。则在 `S` 步之后，

```text
W_S − W_0 = Σ_{j=1}^{J} P^{(j)} R^{(j)},   J = ⌈S/T⌉     (48)
```

从而

```text
rank(W_S − W_0) ≤ min(J·r, m, n) ≤ min(⌈S/T⌉·r, m, n)     (49)
```

**证明。** 每个 `P^{(j)}R^{(j)}` 的秩 ≤ `r`；秩对加法次可加：`rank(A+B) ≤ rank(A)+rank(B)`。
式 (48) 忽略折叠的量化项 `e_fold`（每元素 ≤ `q/2`）；把 `W_S` 换成"量化后的骨架"时结论不变，
只是多一个逐元素的噪声项。∎

**式 (49) 的正确读法。** 它说的是**位移**的秩上界，不是权重的秩，也不是"有效秩一定达到
`J·r`"。一般位置下子空间互不包含，和的确能张满 `J·r` 维；但若梯度长期集中在某几个固定方向，
实际秩会小得多。反过来说，**"GaLore 永久秩受限"是错的**：每个区间内秩 ≤ `r`，跨区间可以累积到
`min(m,n)`。真正的问题是**区间内的截断**，不是全程的秩。

> 这也解释了 ReLoRA（`arXiv:2307.05695`）为什么有效：一串 rank-`r` 更新合并进 `W` 之后，
> 总位移的秩可以到 `K·r`。survey §3.8 把它列为"秩不受限"这一点的出处，是准确的。

### 7.3 刷新间隔的两难

- `T` 太大：由 §2.3，`χ` 在 20 步内就能到 60–80%，区间的大部分时间都在一个坏子空间里工作，
  式 (37) 的下降被打折。
- `T` 太小：SVD 的成本摊销变高（命题 10.1），而且每次换基都要折叠（定理 8.1），
  而折叠是 PCIe 成本（§10.3）。

**我们的选择是 `T = 10`，而理由比原始设计更硬。** 直接测「用 step t−1 的基捕获 step t」：GDN 三层
只剩 **0.20–0.40**（oracle 0.995），L3 稳在 0.81–0.97——一步陈旧就丢掉 60–80% 的能量
（`06` §4.7）。所以 `T = 200–500` 不只是"太久"，它完全没有依据；而 SVD 的成本也不是原来估的
6–9 ms/step，而是**一次刷新步 11.72 s、且只刷一层**（`STATE.md` §5），40 层口径是 `40 × 11.72 / T`
的规模（含诊断的上界，待拆分）。所以 `T` 是**在两种坏之间选**，真正的杠杆是让 SVD 变便宜（§10.3）。

## 8. 折叠：一条可表示性定理

### 8.1 存储形式

我们的权重不是 bf16，而是

```text
W = deq(Ŵ) + P·R                              (50)
```

其中 `Ŵ` 是 int8 码（配每输出通道尺度 `s`，`deq(Ŵ)_{a,b} = Ŵ_{a,b}·s_a`），`P` 是 `m×r` 列正交基，
`R` 是 `r×n` 累加器。`deq(Ŵ)` 是**已经量化好**的实数矩阵，不是任意矩阵——它的每个元素都在网格
`s_a·Z ∩ [−127s_a, 127s_a]` 上。

### 8.2 换基时会发生什么

假设当前基是 `P`，累加器 `R ≠ 0`。现在要换成新基 `P'`（同样列正交）。如果我们天真地保留骨架
不变、只把累加器"换算"到新基，即令 `R' = P'ᵀPR`，那么新的表示是

```text
deq(Ŵ) + P'R' = deq(Ŵ) + P'P'ᵀPR             (51)
```

它与式 (50) 相差

```text
P R − P'P'ᵀ P R = (I − P'P'ᵀ) P R            (52)
```

把 `PR` 按 `P'` 的列空间做正交分解：

```text
P R = P'P'ᵀ P R  +  (I − P'P'ᵀ) P R          (53)
```

第一项在新基里，第二项**不在** `col(P')` 里。

**定理 8.1（换基的可表示性）** 设 `P, P' ∈ R^{m×r}` 均列正交，`R ∈ R^{r×n}`。存在
`R' ∈ R^{r×n}` 使得

```text
P' R' = P R                                   (54)
```

当且仅当

```text
(I − P'P'ᵀ) P R = 0                           (55)
```

当条件成立时，唯一的解是 `R' = P'ᵀPR`。

**证明。** (⇐) 若式 (55) 成立，则 `P'P'ᵀPR = PR`，取 `R' = P'ᵀPR` 得
`P'R' = P'P'ᵀPR = PR`。
(⇒) 若 `P'R' = PR`，则 `PR` 的每一列都在 `col(P')` 里，而 `I − P'P'ᵀ` 正是到 `col(P')` 正交补的
投影，故式 (55) 成立。唯一性：若 `P'R'_1 = P'R'_2`，左乘 `P'ᵀ` 并用 `P'ᵀP' = I_r` 得
`R'_1 = R'_2`。∎

**推论 8.1（天真换基丢掉的东西）**

```text
‖(I − P'P'ᵀ) P R‖_F²  =  ‖P R‖_F² − ‖P'ᵀ P R‖_F²      (56)
```

**证明。** 式 (53) 的两项在 Frobenius 内积下正交（一个是 `col(P')` 分量，一个在正交补里），
再用勾股定理；`‖P'P'ᵀPR‖_F = ‖P'ᵀPR‖_F`，因为 `P'` 列正交。∎

**推论 8.2（随机新基下的期望损失）** 若 `P'` 是在 `R^{m×r}` 的 Stiefel 流形上均匀取的正交基，
且与 `PR` 独立，则

```text
E‖P'ᵀ P R‖_F² = (r/m)·‖P R‖_F²                (57)
E‖(I − P'P'ᵀ) P R‖_F² = (1 − r/m)·‖P R‖_F²    (58)
```

即**期望上丢掉 `sqrt(1 − r/m)` 比例的已累积位移**。

**证明。** 把 `PR` 写成 `Σ_{i≤r}σ_i a_i b_iᵀ`（`a_i` 单位正交，`b_i` 单位正交）。则
`P'ᵀPR = Σ_i σ_i (P'ᵀa_i) b_iᵀ`，而 `b_i` 正交，所以
`‖P'ᵀPR‖² = Σ_i σ_i²‖P'ᵀa_i‖²`。对固定的单位向量 `a`，
`E‖P'ᵀa‖² = E Σ_{k≤r}(p_kᵀa)² = r·E[(p_1ᵀa)²] = r/m`
（`p_1` 均匀分布在单位球面上，`E[(p_1ᵀa)²] = 1/m`）。代回得式 (57)，再用式 (56) 得式 (58)。∎

**数值。** `m = 1024, r = 64`：`sqrt(1 − 64/1024) = sqrt(0.9375) = 96.8%`。

也就是说：**如果先换基、再折叠（或根本不折叠），一次随机换基会丢掉 96.8% 的累积更新。**
这不是"精度损失"，是信息被扔掉了，而且扔掉的正是优化器辛苦攒了 `K` 步的那部分。

### 8.3 结论：折叠必须严格早于换基

**算法上的强制顺序：**

```text
先折叠：  Ŵ ← Q( deq(Ŵ) + P R ) ;   R ← 0
后换基：  P ← SVD_r(G) 的 U_{:,1:r}
```

折叠之后 `R = 0`，式 (55) 的条件平凡成立（`0 = 0`），换基不丢任何东西。定理 8.1 因此不是
"工程建议"，而是"要么这样做，要么承认你在丢信息"的二分法。

**两个容易混淆的点。**

1. **折叠本身有量化误差，但那是另一回事。** 折叠做的是
   `Q(deq(Ŵ) + PR)`，误差 ≤ 半个量化台阶每元素，这是**受控的、有界的**（§2 的 EF 甚至可以把它
   变成零偏的）。定理 8.1 说的是：如果不折叠就换基，误差不是半个台阶，而是 `96.8%` 的位移。
   两者差约两个数量级（0.98% vs 96.8%）。
2. **`P' = P` 时不需要折叠。** 式 (55) 自动成立（`(I − PPᵀ)PR = 0`）。这也解释了为什么"只在
   刷新时才折叠"是充分的：不刷新基的步里，累加器可以一直长。

## 9. 子空间里的 Adam：基相关性与偏差修正

### 9.1 状态是什么

在 `r×n` 空间里跑 Adam，状态是

```text
M_t, V_t ∈ R^{r×n}                            (59)
```

`M_t` 是 `G̃_t` 的一阶矩（动量），`V_t` 是 `G̃_t` 的逐元素二阶矩。更新为式 (4)，方向
`D_t = Φ(G̃_t)`，累加器按式 (8) 走。

### 9.2 换基时什么能带走

`M, V` 的下标是**子空间的坐标**，不是权重空间的坐标。换基 `P → P'` 之后，"新坐标的一阶矩"
应该是 `G̃'_t = P'ᵀG_t` 的指数滑动平均。旧 `M` 是 `PᵀG` 的滑动平均。这两者之间**不存在**一个
只依赖 `P, P'` 的线性变换能把前者精确变成后者，因为滑动平均已经把不同时刻的投影混在一起，
而每个时刻的投影都用了旧的 `P`。

**命题 9.1（可携带的部分）** 把 `M` 解释成权重空间里的动量 `M_W := P M ∈ R^{m×n}`（秩 ≤ `r`）。

(a) 若令

```text
M' := P'ᵀ P M                                 (60)
```

则 `P'M' = P'P'ᵀPM`，即**只保留了 `M_W` 在 `col(P')` 里的分量**，丢掉
`(I − P'P'ᵀ)PM`，其相对大小由推论 8.2 给出（`r/m` 保留率）。

(b) `V` 不能这样搬。`V` 是逐元素方差，不是某个矩阵的线性像。若采用"梯度在旧基下各方向
独立、第 `k` 个方向的方差为 `V[k,j]`（输入通道 `j`）"这个对角模型，则新方向 `p'_i` 上的方差是

```text
V'[i,j] = Σ_{k≤r} (p'ᵢᵀ p_k)² · V[k,j]        (61)
```

写成矩阵形式：

```text
V' = [(P'ᵀP) ⊙ (P'ᵀP)] · V     （⊙ 逐元素乘，· 矩阵乘）   (62)
```

**证明。** 在对角模型下，第 `j` 列的梯度写成 `G[:,j] ≈ Σ_k g_k p_k`，`E[g_k g_l] = δ_{kl}V[k,j]`。
新坐标 `g'_i = p'ᵢᵀG[:,j] = Σ_k (p'ᵢᵀp_k) g_k`，于是
`Var(g'_i) = Σ_k (p'ᵢᵀp_k)² V[k,j]`。∎

**为什么式 (62) 不是"把 `V` 当向量旋转"。** 把 `V` 当向量左乘 `P'ᵀP` 得到的是
`Σ_k (p'ᵢᵀp_k)V[k,j]`，一次幂；正确的方差传播是二次幂。一次幂会把负的相关"抵消"掉，
在子空间重叠度高时低估方差，导致 Adam 的有效步长偏大。这是一个具体、可检查的差别：
`(P'ᵀP)` 的元素有正有负，平方之后全为非负，才符合"方差相加"的语义。

**必须承认的局限。** 式 (61) 仍然只是**模型**：真实二阶矩不是对角，`G` 的坐标之间相关。
`r×n` 的存储装不下完整的 `r×r` 协方差（那是 `r²n`，`r = 64` 时比 `rn` 大 64 倍）。所以任何
携带方案都是近似；式 (62) 是在给定存储下最不坏的那个。

### 9.3 重置矩就必须重置 `t`

**命题 9.2（偏差修正的两种错配）** 设 `β₁ = 0.9, β₂ = 0.999`，在第 `t` 步（`t` 很大）把
`M, V` 清零后立即做一步 Adam。

(a) **清零矩但保留全局 `t`**：第一步 `M = (1−β₁)G̃`，`V = (1−β₂)G̃²`，而偏差修正仍用
`1−β₁^t ≈ 1`、`1−β₂^t ≈ 1`。于是

```text
M̂ = (1−β₁)G̃,   V̂ = (1−β₂)G̃²,   D ≈ sqrt((1−β₂^t)/(1−β₂))·(1−β₁)/(1−β₁^t)·sign(G̃)    (63)
```

在 `t = 1000` 时 `β₂^t = 0.368`，`β₁^t ≈ 0`，所以 `D ≈ 2.5·sign(G̃)`——**第一步比正确值大 2.5 倍**，
而且要大约 `1/(1−β₁) = 10` 步才恢复；`t → ∞` 时 `1−β₂^t → 1`，倍数升到 `0.1/0.0316 = 3.16`
（与 [`04-adamw.md`](04-adamw.md) 要点第 8 条的 3.16 一致：那里取 `t → ∞` 的极限）。
`M̂` 单独看确实"错了 `(1−β₁^t)` 倍"（常见说法），
但 `D` 是 `M̂/√V̂` 的比值，两边的偏差修正不同步，实际后果是**步长偏大**而不是偏小。

(b) **保留矩但重启 `t = 1`**：第一步 `M̂ = M/(1−β₁) ≈ 10·M`，`V̂ = V/(1−β₂) ≈ 1000·V`，
所以 `D ≈ (10/31.6)·sign(G̃) ≈ 0.32·sign(G̃)`——**第一步比正确值小 3 倍**。

**结论。** 矩和 `t` 必须**同进同退**：要么两者都重置（`M = V = 0, t = 1`），要么两者都保留
（用式 60、62 搬运，`t` 不变）。只改一个必然错配，且错配的倍数可以算出来（式 63）。

### 9.4 两种可辩护的选择

| 选择 | 做法 | 代价 | 适用 |
|---|---|---|---|
| **携带**（carry） | `M' = P'ᵀPM`，`V' = [(P'ᵀP)⊙(P'ᵀP)]V`，`t` 不变 | 丢掉 `(I−P'P'ᵀ)PM`（`r/m` 保留率）；`V'` 是对角模型下的近似 | 刷新频繁（`T` 小）、希望动量连续 |
| **重置**（reset） | `M = V = 0`，`t = 1` | 每次刷新后有约 `1/(1−β₁) = 10` 步的"冷启动"，动量信息归零 | 刷新稀疏、实现简单、状态可复现 |

GaLore 原论文选择**携带**（它不做 int8 骨架，`P` 变化时直接把矩留在原处，隐含假设新旧基
足够接近）。**我们的实现现在有刷新**（`refresh_basis`，默认先折叠再换基），并且选了**携带**：
`M' = P'ᵀPM`、`V' = [(P'ᵀP)⊙(P'ᵀP)]V`、`t` 不变；`reset_adam` 可切到重置。理由见 `06` §7 第 4 条。

## 10. 完整算法与成本

### 10.1 算法

下面把 §1–§9 的所有零件装起来。注意第 5 步和第 6 步的顺序是定理 8.1 强制的。

```text
输入：Ŵ (int8 码) , s (每输出通道尺度) , P (m×r 列正交) , R = 0
      M = V = 0 , t = 0 , η , β₁ , β₂ , ε , K , T   （要求 K | T）

每一步 t ← t + 1：
  1  G  ← ∂L/∂W                    # m×n，反传到这一层时拿到；用完即弃
  2  G̃  ← Pᵀ G                     # r×n，投影
  3  M  ← β₁ M + (1−β₁) G̃
     V  ← β₂ V + (1−β₂) G̃²
     D  ← [M/(1−β₁^t)] / ( √[V/(1−β₂^t)] + ε )      # r×n
  4  R  ← R − η D                  # 只累加，不动 Ŵ（式 8）
  5  若 t mod K == 0：             # 折叠
       W_tmp ← deq(Ŵ) + P R        # m×n，只在这一层、这一刻物化
       e     ← W_tmp − Q(W_tmp)    # 量化残差（若启用 EF）
       Ŵ     ← Q(W_tmp)            # int8 码 + 冻结的 s
       R     ← 0
       M     ← M + (1/η)·(1 − 1/β₁)·Pᵀ e    # 可选：子空间投影的误差反馈（负系数）
  6  若 t mod T == 0：             # 刷新（此时 R 必为 0）
       P ← U_{:,1:r}(G)            # 前 r 个左奇异向量；用截断/随机 SVD
       （若选择"携带"：M ← Pᵀ P_prev M_prev，V ← [(PᵀP_prev)⊙(PᵀP_prev)]V_prev）

前向永远用  W_eff = deq(Ŵ) + P R
```

**三处顺序不能换：**

- 第 4 行必须在第 5 行之前：先累加再折叠，折叠的是"到目前为止的全部位移"。
- 第 5 行必须在第 6 行之前：定理 8.1。
- 第 6 行的 SVD 用的是**当前步**的 `G`（第 1 行拿到的）。`G` 与基无关，所以在换基前算它没问题；
  但不能用换了基之后的 `PᵀG` 去反推 `G`。

### 10.2 复杂度

**命题 10.1（每矩阵每步的成本）** 记 `p = min(m,n)`。

| 操作 | flops | 字节（读+写） | 频率 |
|---|---|---|---|
| `G̃ = PᵀG` | `2mnr` | `2mn`（G，bf16）+ `2mr`（P） | 每步 |
| Adam（`r×n`） | `O(rn)` | `4rn`（M,V fp32）+ `2rn`（R） | 每步 |
| `P D` 或折叠时的 `P R` | `2mnr` | `2mn`（物化时） | 每步（物化）或每 `K` 步 |
| 折叠的重量化 | `O(mn)` | `mn`（int8 读）+ `mn`（写） | 每 `K` 步 |
| 截断 SVD（随机化，3 趟） | `≈ 6mnr` | `2mn` + `2mr` | 每 `T` 步 |
| 完整 SVD | `O(mn·p)` | 同上 | 每 `T` 步 |

**摊销到每步：**

```text
flops/step ≈ 2mnr  +  2mnr/K  +  6mnr/T        (64)
```

**代入数字。** `gate_up`：`m=1024, n=2048, r=64` → `2mnr = 2.68×10⁸` flops；
`down`：`m=2048, n=512, r=64` → `1.34×10⁸`。全模型 20,480 个矩阵：

```text
投影       : 10240·2.68e8 + 10240·1.34e8 = 4.12 TFLOP/step
折叠 (K=25): 4.12/25 = 0.165 TFLOP/step
SVD  (T=100, 截断): 约 16.5 TFLOP / 100 = 0.165 TFLOP/step
```

按本地环境 bf16 峰值 118 TFLOP/s（`STATE.md` §1；`bench/roofline.py`，其 JSON 未落盘）：

```text
投影 35 ms/step（峰值；实际窄矩阵远低于峰值，估 70–120 ms，UNVERIFIED）
折叠 1.4 ms/step（峰值）
SVD  1.4 ms/step（峰值；survey §6 给的是 6–9 ms/step，含 4–6× 低效）
```

**结论：** 在 `r = 64, K = 25, T = 100` 这个**示例**下（项目配置是 `r=16, T=10`），GaLore 的**每步**额外计算大约是 40–130 ms，
相对 `STATE.md` §5 账本的 7.30 s 步时不到 2%（下面按 r=64 算；账本用 r=16，这一项按比例减半）。
但**每步**不是全部：一次刷新步比这三项都贵，见 §10.3。

### 10.3 真正的瓶颈：刷新，而不是折叠

折叠要把 34.2 GB 的 int8 专家块写回 host（因为主存在 pinned host RAM）。按 `STATE.md` §1 的
D2H 25.2 GB/s：

```text
34.2 GB / 25.2 GB/s = 1.357 s per fold        （纯 D2H 地板，单次折叠）
```

读的那一侧是**免费**的：折叠发生时，该层的权重已经在 GPU 上（前向/dX 要用），所以
34.2 GB 的读是 HBM 访问（637 GB/s，54 ms），不是 PCIe。真正新增的只有写回。

**但折叠不是最贵的那一项。** 四层实测：普通步 12.08 s、刷新步 23.8 s → 每次刷新多 **11.72 s**。
**这 11.72 s 只覆盖一层**：两个驱动都把刷新逐层轮换，一个刷新步只重拟合一层
（`train/m1_run.py:279-308`；`model4.py` 的 `tgt = (step // refresh) % n_lay`）。所以按"每层每 `T`
步刷一遍"放大到 40 层是 `40 × 11.72 / T`：**T=100 也有 4.7 s/步**。这是**含诊断的上界**——
11.72 s 里还有 `measure()`（每 32 专家 chunk 构造 `P Pᵀ` 与 `bmm(pj,x)`，gu 约 1.65 TFLOP/层·矩阵，
与基本身同量级）和一个 PR 诊断，**生产都不需要**；组件拆分在跑，出来之前**不要引用 40 层刷新数字**。

为什么慢：**不是批处理不够**（`topr_basis` 已按 16 专家一批做 `eigh`/`svd`），而是 `eigh`/`gesvdj`
**算术强度低、不碰张量核**。所以杠杆是换成只做 bmm 的算法（随机 range-finder，CPU 已验证
p=10/q=2 时捕获损失 ≤1e-5），不是调大 batch。**这也是 `T` 的取舍被卡住的地方**：调大 `T` 省钱，
但 GDN 层的基一步就陈旧（`06` §4.7）。**方向不变**：刷新是一阶成本，rank 不是约束——变的是倍率。

## 本篇要点

1. GaLore 的可行性的根是"`Φ` 逐元素"（引理 1.1）：只有先投影再优化，状态才能是 `r×n`；
   反过来先优化再投影，一点内存都省不了。
2. 用 SVD 前 `r` 个左奇异向量的唯一严格理由是 Eckart–Young（定理 4.1、推论 4.1）：
   它最小化 `‖G − PPᵀG‖_F`，最小值是 `sqrt(Σ_{i>r}σ_i²)`。
3. 投影的一步下降保证**没有** `ε_proj` 项（命题 5.2）；投影的代价是把每步下降按
   `1 − ρ²` 打折（推论 5.1），其中 `ρ = ‖(I−PPᵀ)G‖/‖G‖` 是相对尾能量。
4. 带投影误差的收敛界是 `O(1/√T) + ε_proj²`（定理 6.1）。`ε_proj` 不由 GaLore 控制；
   而且这个定理只覆盖 SGD，不能套到 Adam 上。
5. 不换基的 GaLore 位移精确秩 `≤ r`（命题 7.1）；换基后是 rank-`r` 项之和，
   上界 `⌈S/T⌉r`（命题 7.2）。所以"永久秩受限"是误解，"区间内截断"才是真问题。
6. 换基的可表示性是**充要条件**（定理 8.1）：`(I − P'P'ᵀ)PR = 0`。随机换基的期望损失是
   `sqrt(1−r/m)‖PR‖`，`r=64, m=1024` 时是 **96.8%**（推论 8.2）。所以折叠必须早于换基。
7. Adam 的 `M` 可以按 `P'ᵀPM` 携带（丢掉子空间外分量），`V` 的正确变换是 `(P'ᵀP)²V`
   而不是 `P'ᵀPV`（命题 9.1）；重置矩必须同时重置 `t`，否则第一步的步长会差 2.5–3 倍（命题 9.2）。
8. `r=64, K=25, T=100` 时 GaLore 的每步额外计算约 40–130 ms（不到 7.30 s 步时的 2%），但**刷新**
   才是大项，而且它**按层算**：一次刷新步只刷一层、**11.72 s/层**；`40 × 11.72 / T` 在 T=100 也有
   **4.7 s/步**（含诊断的上界，拆分在跑）。成本在 SVD 的算子形态（不走张量核），不在 ALU，
   也不在折叠的 PCIe（命题 10.1、§10.3）。
